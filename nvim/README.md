# Personal LazyVim notes

This is a small LazyVim starter configuration. Press `<Space>` and wait for Which-Key to discover commands.

Leader: `<Space>`

Files/search: `<Space> f f` find files, `<Space> /` project text, `<Space> f r` recent files, `<Space> e` explorer.

LSP/code: `g d` definition, `g r` references, `K` hover/type info, `<Space> c r` rename, `<Space> c a` code action, `<Space> c l` LSP info, `<Space> c o` organize imports.

Movement: `h j k l`, `w`, `b`, `0`, `$`, `g g`, `G`.

Editing: `i`, `a`, `o`, `O`, `Esc`, `u`, `Ctrl-r`, `dd`, `yy`, `p`, `ciw`, `diw`, `ci\"`, `ci(`, `.`.

Windows clipboard: `\"+y`, `\"+yy`, `\"+p`.

The live setup uses Catppuccin Mocha, blink.cmp, Snacks Explorer/Picker, VTSLS, and the TypeScript, JSON, Prettier, and ESLint LazyVim extras.
