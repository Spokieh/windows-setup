# LazyVim Cheat Sheet

> `<leader>` = `Space`  
> Ha nem tudod a shortcutot, nyomj `Space`-t és várj a **Which-Key** menüre.

## 🔎 Files & Search

| Key | Action |
| --- | --- |
| `Space f f` | Find files |
| `Space /` | Search text in project |
| `Space f r` | Recent files |
| `Space e` | Toggle file explorer |

## 💻 Code / LSP

| Key | Action |
| --- | --- |
| `gd` | Go to definition |
| `gr` | Find references |
| `K` | Hover / type information |
| `Space c r` | Rename symbol |
| `Space c a` | Code action / quick fix |
| `Space c l` | LSP info |
| `Space c o` | Organize imports |

## 🧭 Movement

| Key | Action |
| --- | --- |
| `h` `j` `k` `l` | Left / Down / Up / Right |
| `w` | Next word |
| `b` | Previous word |
| `0` | Start of line |
| `$` | End of line |
| `gg` | Start of file |
| `G` | End of file |

## ✏️ Editing

| Key | Action |
| --- | --- |
| `i` | Insert before cursor |
| `a` | Insert after cursor |
| `o` | New line below |
| `O` | New line above |
| `Esc` | Normal mode |
| `u` | Undo |
| `Ctrl-r` | Redo |
| `dd` | Delete line |
| `yy` | Yank line |
| `p` | Paste |
| `ciw` | Change inside word |
| `diw` | Delete inside word |
| `ci"` | Change inside quotes |
| `ci(` | Change inside parentheses |
| `.` | Repeat last change |

## 📋 Windows Clipboard

| Key | Action |
| --- | --- |
| `"+y` | Yank to Windows clipboard |
| `"+yy` | Yank line to Windows clipboard |
| `"+p` | Paste from Windows clipboard |
